## 2. Методология

### 2.1. F-test (ANOVA)

F-test предназначен для выявления тех признаков состояния, которые влияют на интегральную оценку счастья больше всего.

Тест строится на начальном предположении $H_0$ о равенстве среднего значения состояния $X$ во всех группах счастья $Y$:

$$H_0: \mu_1 = \mu_2 = ... = \mu_C$$

F-статистика для теста рассчитывается как отношение межгрупповой дисперсии к внутригрупповой. Эта статистика сравнивается с предельным значением, и признаки состояния с F-статистикой меньше предельного значения принимаются за статистически значимые:

$$F = \frac{MS_{between}}{MS_{within}} = \frac{\frac{SS_{between}}{C-1}}{\frac{SS_{within}}{N-1}}$$

где $SS_{between} = \sum_{c = 1}^{C}\sum_{n = 1}^{N}(X_{c} - X)$, $SS_{within} = \sum_{c = 1}^{C}\sum_{n = 1}^{N}(X_{nc} - X_c)$.

### 2.2. F-test для линейной регрессии

F-test одномерной линейной регрессии предназначен для определения влияния непрерывных признаков-причин на непрерывные признаки-состояния.

Он строится на начальном предположении об обнулении веса $\beta$ в уравнении линейной регрессии:

$H_0: Y = \beta_0 + \beta_1 * Y, \beta_1 = 0$

F-статистика теста (для одномерной регрессии) рассчитывается как отношение квадрата коэффициента Пирсона к противоположной относительно единицы величине, умноженной на $(n-2)$:

$$F = \frac{r^2}{1-r^2}\cdot (n-2)$$

### 2.3. L-2 регуляризация, ординальная регрессия

L-2 регуляризация применяется для получения более сглаженных весов модели и заключается в добавлении штрафа за сумму весов к общей функции потерь:

$$L = \sum_{i=1}^{n}(y_i - y_{pred})^2 + \alpha\sum_{j=1}^{p}\omega_j^2$$

Так как таргетная переменная имеет интегральный смысл (распределение по шкале от худшего к лучшему), имеет смысл учитывать разницу в расстоянии от прогноза до истинного значения по интегральной шкале.

Для этого применяется метод математического ожидания рангов, который заключается в получении оценок вероятности:

$$P = [p_0, p_1, \dots, p_{K-1}], \quad \sum_{k=0}^{K-1} p_k = 1.0$$

вычисления математического ожидания ранга по сумме произведения вероятности на ранг:

$$E[Rank] = \sum_{k=0}^{K-1} k \cdot p_k^{(T)}$$

округлении и проецировании на дискретную шкалу:

$$\hat{k} = \text{clip}(\text{round}(E[Rank]), 0, K-1).$$

Также введен параметр температуры, влияющий на функцию принятия решений:

$$p_i^{(T)} = \frac{p_i^{1/T}}{\sum_{j=0}^{K-1} p_j^{1/T}}$$
